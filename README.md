# LifeBalance Privacy Policy

Public policy for LifeBalance 1.4.0, effective November 2, 2026.

- English: https://fasterthanslow.github.io/lifebalance-privacy/
- Russian: https://fasterthanslow.github.io/lifebalance-privacy/ru/
- Publisher/contact: Green Key Universe, greenkeyuniverse@gmail.com

`content.json` is the policy source. Run `python3 build.py` after editing it.
The generated `index.html` and `ru/index.html` are served directly by GitHub Pages
from the root of `main`, with `.nojekyll`; no JavaScript, external fonts, analytics,
build dependencies or custom Actions workflow are added.

The previous Google Docs text is preserved in `previous-policy-2026-01-18.txt` for
history, not as the current policy. The current publication repository contains
only these policy files and no application source, secrets or analytics reports.

Future changes: edit this source, regenerate both HTML files, and publish the same
files to `FasterThanSlow/lifebalance-privacy`. Keep the public URL stable.

This document describes the current implementation. It does not itself implement
analytics consent controls or update store Data safety/App Privacy declarations.
